## 1. Phase 1 — Critical Import Defect & Resolution

### 1.1 Defect Discovery and Root Cause
In S3.5.4A, `sales_engine/llm_gateway/errors.py` introduced diagnostic fields on [LLMRateLimitError](file:///C:/Sales-AI/SalesAI/sales_engine/llm_gateway/errors.py#L140):
```python
def __init__(
    self,
    message: str = "LLM provider rate limit exceeded.",
    provider: Optional[str] = None,
    task_id: Optional[str] = None,
    cause_category: str = "UNKNOWN_RATE_LIMIT",
    retry_after_seconds: Optional[float] = None,
    definitive_cause_proven: bool = False,
    diagnostic: Optional[Any] = None,
):
```
Line 7 imported only `from typing import Optional`. `Any` was omitted.

**Why did tests pass in Python 3.14?**  
Python 3.14 implements PEP 649 (deferred evaluation of annotations), storing annotations in `__annotate__` closures rather than evaluating them at function definition time. However, in Python <= 3.13, or whenever type inspection (`typing.get_type_hints(err.LLMRateLimitError.__init__)`) is invoked, the missing symbol raises:
```text
NameError: name 'Any' is not defined. Did you mean: 'any'?
```

### 1.2 Implemented Fix
In [sales_engine/llm_gateway/errors.py](file:///C:/Sales-AI/SalesAI/sales_engine/llm_gateway/errors.py#L7):
```python
from typing import Optional, Any
```
An automated audit across all internal classes and functions in `sales_engine` confirmed that all 32 modules evaluate type hints with zero missing annotations.

1. **Strict Candidate Scoping:** Applicable only to provider `cohere` and candidate `t2_c2`. Specifying `--require-cohere-trial` with another provider (e.g., `--provider groq`) or candidate (e.g., `--candidate t1_c1`) raises `COHERE_TRIAL_GUARD_VIOLATION`.
2. **Active Live Preflight (`_verify_cohere_live_trial_entitlement`):**
   - Queries `https://api.cohere.com/v1/models?page_size=100`.
   - Requires presence of `x-trial-endpoint-call-limit` and `x-trial-endpoint-call-remaining`. If headers are absent, the key is classified as a Production / Paid key and rejected.
   - Enforces `x-trial-endpoint-call-remaining > 0`. Fails closed if quota is exhausted.
   - Confirms target model `command-r-08-2024` exists in the live catalog.
   - Runs during `_configure_live_candidate` before any financial reservation or inference dispatch.
3. **No Override:** `--confirm-paid` does not override `--require-cohere-trial`.
