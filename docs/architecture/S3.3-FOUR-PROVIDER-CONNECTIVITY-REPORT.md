## 1. Executive Summary

SalesAI S3.3 establishes multi-provider HTTPS connectivity support for four independent LLM providers across dedicated Tier 1 candidate slots:
1. **OpenAI** (`openai`): `gpt-6-luna` -> `t1_c1` (Verified paid baseline from S3.2)
2. **Google Gemini** (`gemini`): `gemini-2.5-flash-lite` -> `t1_c2` (`VERIFIED_FREE_TIER`)
3. **GroqCloud** (`groq`): `openai/gpt-oss-20b` -> `t1_c3` (`VERIFIED_FREE_TIER`)
4. **xAI Grok** (`xai`): `grok-4-fast` -> `t1_c4` (`UNKNOWN` billing; **metadata-only by default; text generation locked**)

All implementations reuse the existing lightweight, zero-SDK `OpenAIProvider` HTTPS adapter and enforce strict endpoint allowlists, isolated environment credentials, two-key execution gates (`--live --confirm-paid`), conservative liability reservations with zero-spend free-tier reconciliation, and fail-closed candidate bindings.

**Zero real LLM inference calls were made during this development task.** All verification was conducted with `httpx.MockTransport`, deterministic offline scoring, and unit/regression test suites.

### Key Guarantees:
- **No Cross-Vendor Fallback**: If `GEMINI_API_KEY` is missing, the adapter never reads `OPENAI_API_KEY` or any other key.
- **Strict HTTPS Endpoint Allowlists**: Rejects localhost, loopback, private IPs (`10.*`, `192.168.*`, `127.*`), non-HTTPS schemes, and unapproved external hosts.
- **Token Parameter Keying**: Gemini and Groq send `max_tokens`; OpenAI luna sends `max_completion_tokens`.
- **xAI Grok Generation Lock**: Attempting live generation with `xai` without `--allow-xai-paid` immediately raises `LLMNotConfiguredError` with `XAI_GENERATION_DISABLED`.
- **Free-Only Gate**: With `--free-only`, attempting generation on non-`VERIFIED_FREE_TIER` providers immediately raises `LLMNotConfiguredError` with `FREE_ELIGIBILITY_UNCONFIRMED`.

## 3. Pricing and Ledger Accounting

1. **Preflight Liability Reservation**: For all providers (including free tier), the budget ledger reserves funds against daily/monthly ceilings using conservative list price upper bounds (`ESTIMATED_LIST_PRICE_UPPER_BOUND`).
2. **Free-Tier Post-Response Reconciliation**: For `VERIFIED_FREE_TIER` models (Gemini and Groq), actual spend in the SQLite ledger reconciles to `$0.000000` with provenance `VERIFIED_FREE_TIER`.
3. **Missing Usage Safeguard**: If an external provider response omits token counts, the reservation is retained against budget and flagged as `UNCERTAIN` for operator review; it is never treated as `$0.00`.
4. **Physical Dispatch Cap**: `--max-requests 1` and `--connectivity-smoke` strictly prevent subsequent fixture dispatch once the cap is reached.
