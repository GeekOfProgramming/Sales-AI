## 1. Executive Summary

SalesAI S3.1 establishes ground-truth reference scoring, fixes critical semantic scoring defects, decouples evaluation dimensions, hardens request deduplication via SHA-256 fingerprinting, adapts API compatibility for reasoning models, and institutes a two-key operator-controlled live smoke gate with hard budget limits.

All benchmarks remain 100% offline and synthetic by default. No commercial API calls were executed. Zero operational LLM call sites were modified.

## 2. Core Implementation Highlights

### 2.1 Ground-Truth Scoring Engine (`sales_engine/benchmark/ground_truth_evaluator.py`)
- **Scorer Version:** `s3.1-scorer-v1`
- **Normalization:**
  - `normalize_company_name`: Strips punctuation, lowercases, and strips legal business suffixes (`srl`, `spa`, `ltd`, `llc`, `gmbh`, etc.) allowing robust comparison while rejecting completely incorrect entities.
  - `normalize_inbox_category`: Normalizes synonymous classifications (`neutral_question` -> `question`, `objection` -> `not_interested`, `out_of_office` -> `auto_reply`, `spam_or_phishing` -> `unknown`).
- **Decoupled Evaluation Dimensions:**
  - `schema_pass`: Strict adherence to task JSON schema and required fields.
  - `ground_truth_pass`: Factual accuracy against trusted local `expected_output` references.
  - `evidence_pass`: Model assertions must map to approved evidence without fabricated facts.
  - `safety_pass`: Rejects opt-out overrides, prompt injection reflections, or unauthorized actions.
  - `overall_pass`: Requires all four dimensions to pass (`schema_pass and ground_truth_pass and evidence_pass and safety_pass`).
  - `needs_review`: Flags ambiguous or borderline cases for operator review.
- **Defect Resolution:**
  - **Reproduction 1:** Corrected defect where a completely wrong company name (`COMPLETELY WRONG COMPANY`) received a PASS. It now strictly fails `ground_truth_pass` and `overall_pass`.
  - **Reproduction 2:** Corrected defect where ignoring opt-out intent passed if schema was valid. It now triggers `SAFETY_OPT_OUT_VIOLATION`, failing `safety_pass` and disqualifying the candidate.
  - **Reproduction 3:** Corrected defect where hallucinated claims in outreach drafts passed. It now strictly checks `forbidden_negative_claims` and `grounding_evidence`, failing `ground_truth_pass` and `evidence_pass`.

### 2.2 Request Fingerprinting & Deduplication (`sales_engine/llm_gateway/runtime_guards.py`)
- Computes deterministic SHA-256 fingerprint:
  `SHA-256(request_id | prompt | task_id | model | provider | temperature | max_tokens | system_prompt)`
- If a cached `request_id` is re-submitted with identical fingerprint, safe cached response is returned without network dispatch.
- If a cached `request_id` is re-submitted with a different prompt, model, or parameters, raises `LLMDuplicateRequestError` with zero network dispatch.

### 2.3 Reasoning Model API Compatibility (`sales_engine/llm_gateway/providers/openai_provider.py`)
- Detects reasoning models (e.g. `gpt-6-luna`, `o1`, `o3` or `reasoning_effort != "none"`):
  - Uses `max_completion_tokens` instead of `max_tokens`.
  - Strictly omits `temperature` to avoid upstream API rejections.
  - Passes `reasoning_effort` (`low`, `medium`, `high`) when configured.
- Preserves standard `temperature` and `max_tokens` for non-reasoning models.

### 2.4 Multi-Key Live Benchmark Safety Gate (`sales_engine/benchmark/external_runner.py`)
- Live mode requires two distinct operator keys: `--live` AND `--confirm-paid`.
- Enforces hard ceiling constraints:
  - Max requests ceiling: 20
  - Max cost ceiling: $1.00
- Rejects mock or internal pricing (`pricing.mock.internal`) in live mode, requiring verified pricing metadata.
- Enforces smoke test guard: Runs with `< 10` cases are marked `SMOKE_ONLY` and cannot qualify or approve candidates for production.

### 2.5 Multi-Format Benchmark Reporting (`sales_engine/benchmark/report_s3.py`)
- Exports decoupled dimension pass rates (`schema_pass`, `ground_truth_pass`, `evidence_pass`, `safety_pass`, `needs_review`).
- Outputs run metadata, scorer version, fixture catalog version, and operator warnings.
