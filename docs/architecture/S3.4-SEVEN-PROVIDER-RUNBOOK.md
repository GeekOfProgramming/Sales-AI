# SalesAI S3.4 — Seven-Provider Runbook: Safe Probing & Operator Smoke

This runbook provides the exact PowerShell commands for the human operator to load protected DPAPI credentials, execute non-chargeable metadata probes across all seven providers, and safely execute single-case connectivity smoke tests.

---

## 1. Safety Principles & Operator Boundaries

1. **Explicit Two-Key Live Execution Gate**:
   Live physical dispatch requires both `--live` and `--confirm-paid` (or `--free-only` for verified free providers). Omission of either flag triggers immediate fail-closed termination.
2. **Strict Physical Request Ceiling**:
   Every live smoke run MUST specify `--max-requests 1` and `--connectivity-smoke`. The runner will abort if more than one request is attempted.
3. **Synthetic Fixtures Only**:
   All benchmark fixtures (`web_a_01`) use purely synthetic test data. **Real customer, lead, company, or internal pyBIM data must never be transmitted to external models.**
4. **No Implicit Fallback**:
   If an external provider returns an error (HTTP 401, 429, 500), the runner halts immediately. No automatic retries or fallback to secondary paid providers will occur.
5. **No Production Activation**:
   All benchmark outputs are tagged `SMOKE_ONLY / NOT MODEL-QUALIFIED` and do not activate production routing.

## 2. Step 1: DPAPI Credential Loading (Session Environment Only)

The operator executes the protected PowerShell helper to load encrypted credentials from Windows DPAPI (`%APPDATA%\pyBIM\SalesAI\api-secrets`) into current session environment variables.

> **Security Note**: This command injects keys into the current PowerShell process memory only. It never writes keys to disk, log files, or terminal stdout.

```powershell
# Execute from C:\Sales-AI\SalesAI
.\scripts\SALESAI-SEVEN-PROVIDERS.ps1 -Mode Load
```

To verify environment variable presence without printing secret values:
```powershell
Get-ChildItem Env: | Where-Object { $_.Name -match "(KEY|TOKEN|ACCOUNT_ID)" } | Select-Object Name, @{Name="Configured"; Expression={ if ($_.Value.Length -gt 0) { "YES (" + $_.Value.Length + " chars)" } else { "NO" } }}
```

## 7. Stop Conditions & Escalation

Halt testing and report immediately if:
1. Any error code 429 (rate-limit / quota exhausted) occurs.
2. A provider response returns unexpected HTML or 5xx gateway errors.
3. The budget reservation is flagged as `UNCERTAIN`.
4. Any attempt is made by the system to fallback to another provider.
