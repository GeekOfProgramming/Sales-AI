## 1. Free-Tier Classification Hardening

### 1.1 Problem Statement
Prior to S3.5.3A:
- Any model request to provider `groq` was automatically classified as `VERIFIED_FREE_TIER` via `if pid == "groq": return "VERIFIED_FREE_TIER"`.
- Any model ID containing `gemini` was classified as free via `if "gemini" in mid: return "VERIFIED_FREE_TIER"`.
- This created a safety vulnerability where unverified, paid, or custom models could bypass the `--free-only` gate.

### 1.2 Implemented Architectural Safeguards
1. **Explicit Model Allowlist:** Replaced generic wildcards with `EXPLICIT_VERIFIED_FREE_MODELS` in [sales_engine/benchmark/provider_catalog.py](file:///c:/Sales-AI/SalesAI/sales_engine/benchmark/provider_catalog.py#L406-L435):
   ```python
   EXPLICIT_VERIFIED_FREE_MODELS: Dict[str, Set[str]] = {
       "gemini": {
           "gemini-2.5-flash-lite",
           "gemini-3.5-flash-lite",
       },
       "groq": {
           "openai/gpt-oss-20b",
       },
   }
   ```
2. **Fail-Closed Classification:**
   - Groq models other than `openai/gpt-oss-20b` (e.g., `llama-3.3-70b-versatile`, `mixtral-8x7b-32768`) return `UNKNOWN`.
   - Gemini models other than `gemini-2.5-flash-lite` and `gemini-3.5-flash-lite` (e.g., `gemini-1.5-pro`, `gemini-ultra`) return `UNKNOWN`.
   - OpenRouter models lacking the explicit `:free` suffix return `VERIFIED_PAID`.
   - OpenAI returns `VERIFIED_PAID`.
   - Cohere, NVIDIA, Cloudflare, xAI, and unknown providers return `UNKNOWN`.
3. **Dynamic Gate Enforcement in Runner:** Updated [sales_engine/benchmark/external_runner.py](file:///c:/Sales-AI/SalesAI/sales_engine/benchmark/external_runner.py#L618-L627) to dynamically evaluate `classify_model_billing(spec.provider_id, spec.exact_model_id)` during preflight, blocking execution if the dynamic classification is not `VERIFIED_FREE_TIER`.
4. **Deterministic Unit Tests:** Added 9 focused tests in [tests/test_s3_5_3_groq_hardening.py](file:///c:/Sales-AI/SalesAI/tests/test_s3_5_3_groq_hardening.py) confirming that unverified Groq/Gemini models fail closed.
