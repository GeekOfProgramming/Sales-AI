# SalesAI S3.1 — Deferred Issues & Pragmatic Scope Register

**Date:** 2026-10-22  
**Status:** Approved Deferred Register  
**Governing Rule:** Pragmatic delivery over non-blocking hardening; fix issues affecting benchmark validity, unintended spending, or essential safety; defer non-blocking enhancements to subsequent phases.

## 2. Invariant Commitments

1. No deferred item impairs benchmark safety, budget containment, or ground-truth evaluation integrity.
2. The two-key live authorization gate (`--live` + `--confirm-paid`) and request/spend ceilings ($1.00 max, 20 reqs max) remain unconditionally enforced.
3. Operational call sites remain strictly isolated from benchmark experimentation.
