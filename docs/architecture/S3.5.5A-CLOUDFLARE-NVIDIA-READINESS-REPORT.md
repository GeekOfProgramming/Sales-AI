### Rate Card Corrections
Previous catalog entries listed stale pricing of $0.05 / $0.20 per 1M tokens. Official Cloudflare documentation establishes:
- **Input Pricing:** **$0.152 per 1M tokens**
- **Output Pricing:** **$0.287 per 1M tokens**
- Stale pricing ($0.05 / $0.20) was purged from `sales_engine/benchmark/provider_catalog.py` and `sales_engine/llm_gateway/model_catalog.py`.

### Neuron Billing Model & Accounting Conversion
Cloudflare Workers AI bills exclusively in **Neurons**:
- **Pricing per Neuron:** $0.011 per 1,000 Neurons ($0.000011 per Neuron).
- **Neuron Conversion Factors (for `@cf/meta/llama-3.1-8b-instruct-fp8`):**
  - Input tokens: $\frac{0.152}{0.000011} \approx 13,818.18$ Neurons per 1M input tokens ($\approx 0.013818$ Neurons/token).
  - Output tokens: $\frac{0.287}{0.000011} \approx 26,090.91$ Neurons per 1M output tokens ($\approx 0.026091$ Neurons/token).
- **Neuron Formulas implemented in `sales_engine/llm_gateway/providers/cloudflare_provider.py`:**
  $$\text{Input Neurons} = \lceil\text{input\_tokens} \times 0.01381818\rceil$$
  $$\text{Output Neurons} = \lceil\text{output\_tokens} \times 0.02609091\rceil$$
  $$\text{Total Neurons} = \text{Input Neurons} + \text{Output Neurons}$$
  $$\text{Cost (USD)} = \text{Total Neurons} \times 0.000011$$
- **Free Allocation:** Cloudflare grants **10,000 Neurons/day** across all Workers AI usage on the account.
  - A benchmark case consuming 500 input tokens and 500 output tokens uses $\approx 7 + 14 = 21$ Neurons, well below the 10,000 daily allocation.
  - However, token-based USD pricing alone does not guarantee a zero-charge outcome because overages depend on account plan status.
