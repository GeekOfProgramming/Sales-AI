# SalesAI S3.3 — Four-Provider Operator Runbook

This runbook provides the exact PowerShell CLI commands for the operator to probe credentials and run one-case connectivity smoke tests across Google Gemini, GroqCloud, OpenAI, and xAI Grok.

**CRITICAL RULES:**
- All commands MUST be executed in the **same PowerShell process** where the environment variables are set.
- Never print, echo, or commit API key values.
- Connectivity smoke results are marked `SMOKE_ONLY` and do NOT select a production model.
- Keep all company records, email data, customer information, and pyBIM data local. Use only synthetic benchmark fixtures.

## Step 2: One-Case Free-First Connectivity Smoke Tests

These commands execute one single fictional test case (`website_extraction:pass_a / web_a_01`) under strict safety ceilings:
- Hard cap: 1 case (`--max-cases 1`)
- Hard cap: 1 request (`--max-requests 1`)
- Budget cap: $0.01 (`--max-cost-usd 0.01`)
- Two-key approval: `--live --confirm-paid` (required permission to transmit the synthetic prompt)
- Fail-closed free gate: `--free-only`

### A. Run Google Gemini Free-Tier Smoke:
```powershell
python scripts/benchmark_external_llm.py `
    --live `
    --confirm-paid `
    --provider gemini `
    --free-only `
    --connectivity-smoke `
    --task website_extraction:pass_a `
    --max-cases 1 `
    --max-requests 1 `
    --max-cost-usd 0.01 `
    --db-path data/benchmark_budget.db `
    --output-dir runtime/smoke_gemini
```

### B. Run GroqCloud Free-Plan Smoke:

## Step 3: Audit Ledger & Verify Spend

After running smoke tests, verify the local SQLite ledger:

```powershell
# View recent reservations in budget ledger
python -c "
import sqlite3
conn = sqlite3.connect('data/benchmark_budget.db')
cursor = conn.cursor()
cursor.execute('SELECT reservation_id, request_id, model, status, final_cost_usd, failure_code FROM llm_reservations ORDER BY created_at DESC LIMIT 10;')
for row in cursor.fetchall():
    print(row)
conn.close()
"
```

Verify that Gemini and Groq show `final_cost_usd = 0.0` and `status = RECONCILED`.
