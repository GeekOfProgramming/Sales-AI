# قالب‌های جلسات pyBIM برای Gmail

## محتویات

- `pyBIM_Meeting_EN_Dark.html`: دعوت جلسه انگلیسی، تم تیره
- `pyBIM_Meeting_EN_Light.html`: دعوت جلسه انگلیسی، تم روشن
- `pyBIM_Meeting_IT_Dark.html`: دعوت جلسه ایتالیایی، تم تیره
- `pyBIM_Meeting_IT_Light.html`: دعوت جلسه ایتالیایی، تم روشن
- `pyBIM_Meeting_Studio.html`: سازنده تعاملی با قابلیت ویرایش جلسه و کپی خروجی برای Gmail
- `pyBIM_Meeting_4_Designs.png`: پیش‌نمایش هر چهار طراحی

## روش توصیه‌شده

1. فایل `pyBIM_Meeting_Studio.html` را در مرورگر Chrome باز کنید.
2. زبان و رنگ را انتخاب کنید. می‌توانید متن را برای دعوت جلسه (Invitation) یا تأیید جلسه (Confirmation) تنظیم کنید.
3. نام مخاطب، موضوع، تاریخ، ساعت، منطقه زمانی و لینک واقعی جلسه را وارد کنید. سه دستورجلسه را نیز می‌توانید اصلاح کنید.
4. در صورت نیاز رنگ آبی و سرمه‌ای برند را با HEX واقعی تغییر دهید.
5. دکمه «کپی ایمیل فرمت‌شده برای Gmail» را بزنید. سپس در Gmail > Compose کلیدهای Ctrl+V را بزنید.
6. دکمه «کپی Subject» را بزنید و عنوان را در فیلد Subject درج کنید.
7. پس از بررسی خروجی، برای استفاده مجدد از گزینهٔ Gmail > سه‌نقطه > Templates > Save draft as template > Save as new template استفاده کنید.

### فعال کردن Templates در Gmail

Settings > See all settings > Advanced > Templates > Enable > Save Changes

### نکات فنی

- Gmail معمولی ویرایشگر Source/HTML خام ندارد. سورس HTML را مستقیماً در بدنه ایمیل Paste نکنید؛ باید **خروجی رندرشده** را کپی کنید.
- در صورت ممنوعیت دسترسی Clipboard در مرورگر، در Studio روی «انتخاب بدنه برای کپی دستی» بزنید، سپس Ctrl+C و Ctrl+V.
- با قالب‌های مستقل هم می‌توانید HTML را در Chrome باز کنید و فقط محتوای طراحی‌شده را انتخاب و در Gmail Paste کنید؛ Studio روش ساده‌تر و کم‌خطاتری است.
- در صورت وجود امضای پیش‌فرض Gmail، قبل از ارسال امضای اضافی را از متن حذف کنید.
- لوگو از آدرس عمومی وب‌سایت بارگذاری می‌شود؛ برخی گیرندگان نمایش عکس خارجی را غیرفعال می‌کنند.
- این قالب ایمیل است، نه دعوت‌نامه تقویم با RSVP. برای افزودن رویداد به تقویم گیرنده باید Google Calendar invite جداگانه ارسال شود.
- قبل از استفاده واقعی، ایمیل تستی ارسال کنید و روی موبایل و دسکتاپ آن را ببینید.
- رنگ‌های اولیه از نمونه بصری سایت برآورد شده‌اند؛ کدهای HEX دقیق در ورودی Studio قابل تنظیم‌اند.
