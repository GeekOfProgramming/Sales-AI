# pyBIM — Gmail Meeting Templates

**Four reusable HTML meeting invitations**

- `pyBIM_Meeting_EN_Dark.html`
- `pyBIM_Meeting_EN_Light.html`
- `pyBIM_Meeting_IT_Dark.html`
- `pyBIM_Meeting_IT_Light.html`

**Recommended:** Open `pyBIM_Meeting_Studio.html` in Chrome on your computer. Choose a language/theme; enter recipient, topic, date/time, meeting URL, and agenda. Press **Copy formatted email for Gmail**. Open Gmail > Compose and paste using Ctrl+V. Use the separate **Copy Subject** button for the subject line.

If browser clipboard permissions prevent direct copying, press **Select email body**, then Ctrl+C, then paste into Gmail. Do not paste the raw HTML source into Gmail.

Gmail reusable templates: Settings > See all settings > Advanced > Templates > Enable > Save changes. After pasting the formatted email, Compose > More options (...) > Templates > Save draft as template > Save as new template. On later use, insert the template and edit recipient/date/time/link.

If Gmail auto-inserts a default signature, delete that duplicate block in Compose, or change the Gmail signature setting for those accounts.

Brand colors initially inferred from the supplied pyBIM screenshot: dark navy, white/light slate, and blue accents. The Studio has editable brand blue and navy controls. Inline CSS, table-based layout, no JavaScript in the actual emails. Arial/Helvetica font stack. The website-hosted white pyBIM logo is referenced remotely; mail clients may block external images until opened.

Never send while placeholder fields remain or meeting URL is invalid. Final Gmail rendering may differ from preview; send yourself a test.
